# Лаба 9 — Управление затратами в облаке (FinOps): ценообразование, распределение затрат, оптимизация

## 1. Цель работы

Закрепить на практике знания по методологии FinOps и управлению облачными затратами:
- выбрать и обосновать модель ценообразования для разных типов нагрузки (`On-Demand`, `Reserved` / `CVoS`, `Spot` / `Preemptible`);
- рассчитать экономию серверной инфраструктуры и хранилищ на официальном калькуляторе Yandex Cloud;
- внедрить дисциплину тегирования ресурсов (`env`, `project`, `team`, `cost_center`) и устранить финансовую «чёрную дыру»;
- настроить проектный бюджет и каскадные алерты (50%, 80%, 100%) в Yandex Cloud Billing;
- применить методы оптимизации утилизации: Rightsizing, Auto-scaling группы веб-серверов и интеллектуальный Lifecycle в Object Storage;
- задокументировать получившуюся модель затрат в отчёте.

## 3. Исходные данные

**Проект:** Сервис «Почини.Онлайн» (`pochini.online`)  
**Компоненты инфраструктуры:**
* **Веб-фронтенд (SPA, Nginx):** Базовая нагрузка 24/7 + дневные пики заявок.
* **API-бэкенд:** Микросервисы бизнес-логики (заказы, чаты, поиск СТО).
* **База данных:** Кластер PostgreSQL (master/replica), непрерывная работа 24/7/365.
* **Тестовая среда:** Dev/QA стенд для проверок и тестирования в рабочие часы.
* **Хранилище объектов:** Yandex Object Storage (статика, фото ремонта, бэкапы, архивы).
