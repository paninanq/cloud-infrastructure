# Лаба 5 — Хранилища данных в облаке (Block, File, Object: выбор и применение)

## 1. Цель работы

Закрепить на практике знания по выбору и проектированию облачных хранилищ данных:
- классифицировать и различать три типа облачных хранилищ — **Block**, **File** и **Object**;
- выбирать и применять специализированные сервисы AWS (**EBS**, **EFS**, **S3**) и их аналоги в Yandex Cloud и VK Cloud;
- учитывать баланс производительности и стоимости (IOPS, Throughput, Latency);
- выстраивать гибридную архитектуру хранения данных без переплат;
- настраивать жизненные циклы (Lifecycle Rules), версионирование и защиту данных.

## 3. Исходные данные

**Проект:** Сервис «Почини.Онлайн» (`pochini.online`)  
**Компоненты хранения:**
- **Веб-фронтенд (статика):** Amazon S3 Standard + CloudFront CDN.
- **API-бэкенд (виртуальные машины):** Amazon EBS gp3 (системные диски).
- **База данных (PostgreSQL):** Amazon EBS io2 / gp3 с регулярными региональными снапшотами.
- **Общий каталог (Shared media):** Amazon EFS (NFSv4.1 Multi-AZ).
- **Бэкапы и архивы:** Amazon S3 Standard-IA / Glacier Flexible Archive с жизненными циклами и Object Lock.
