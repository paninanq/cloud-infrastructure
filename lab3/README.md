# Лаба 3 — Проектирование сетевой архитектуры облака (VPC, балансировщики, связность)

## 1. Цель работы

Закрепить на практике основы сетевой архитектуры облака:
- спроектировать виртуальную частную сеть (VPC) с несколькими зонами доступности;
- выбрать и настроить балансировщик нагрузки под конкретный сервис;
- обеспечить связность подсетей с внешним миром (IGW, NAT);
- применить чек-лист проектирования и избежать типичных ошибок;
- задокументировать получившуюся сеть.

## 3. Исходные данные

**Название сервиса:** *Почини.Онлайн* (`pochini.online`)  
**Тип сервиса:** *Онлайн-платформа поиска автосервисов и организации ремонта автомобилей (маркетплейс услуг с личными кабинетами клиентов, механиков и автосервисов).*  
**Целевая аудитория:** *Владельцы автомобилей, механики и автосервисы.*  

**Основные сервисы:**
- **Веб-клиент:** Публичный фронтенд (HTTPS, статика/SPA, кэширование).
- **API Gateway:** Входная точка в бэкенд (`/api/*`, `/orders/*`, WebSocket).
- **Микросервисы бизнес-логики:** User-ID, Products, Chats, Search, Notifier.
- **База данных и кэш:** PostgreSQL (master/replica в 3 AZ), Redis, RabbitMQ.
