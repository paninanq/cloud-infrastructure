# Облачная инфраструктура

## Авторы работ: Панин Дмитрий и Панина Анна.


Мы смотрим на облако с двух сторон сразу. С одной — **как устроено само облако**: виртуальные сети и балансировщики, типы хранилищ, разграничение доступа и секреты, деньги и отказоустойчивость. С другой — **какие системы в этом облаке живут и кто их поддерживает**: базы данных, брокеры сообщений, поиск, мониторинг, CI/CD. Лекции идут вперемешку, чтобы теория облака и практика эксплуатации шли рядом.
